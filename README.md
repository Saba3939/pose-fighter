# POSE FIGHTER

カメラで読み取ったポーズで攻撃・ガード・3連撃を操作する、移動なしの2人対戦ゲームです。

## 起動

Node.js 24、Google Chrome、Webカメラを使用します。EMEET C960を想定しています。

```bash
npm install
npm run dev
```

`http://127.0.0.1:5173/` または `http://127.0.0.1:5173/game.html` を開いて「対戦スタート」を押します。カメラの使用を許可し、鏡映しの映像の左側に1P、右側に2Pが立つとカウントダウンが始まります。肩と手首が映るようにしてください。足や腰は判定に使いません。

画面は対戦に必要なHP、残り時間、キャラクター、ヒット演出を中心にしています。カメラ映像は右下の小窓に表示します。左下の「設定」から映像を隠したり、カメラを選択したりできます。

## 操作と対戦ルール

左右は本人の左右です。

| ポーズ | 技 | 特徴 |
| --- | --- | --- |
| 左手だけUP | ジャブ | 素早い攻撃。6ダメージ |
| 右手だけUP | ストレート | ジャブからつながる攻撃。単発で9ダメージ |
| 両手UP | 強攻撃 | 出は遅いがガードを崩す。単発で16ダメージ |
| 腕クロス | ガード | 通常攻撃を防ぐ |
| 両腕を横に開く | コンボ脱出 | 被弾中に使用。EXを50消費 |
| 片腕だけ横に開く | カウンター | ジャブ・ストレートを受けると12ダメージの反撃 |
| 片腕を上、反対の腕を横にするL字 | 必殺技 | EXを100消費。単発30ダメージ。ガード可能 |

手首を肩より十分上に上げ、片手の技では反対の手を下げます。ガードは胸の前で手首を交差させます。攻撃はポーズを作ったときに1回だけ出ます。同じ攻撃を繰り返すときは、一度手を下げてください。

ジャブが当たったら、右手UP、両手UPとつなぐと3連撃になります。命中から850ms以内に次の技を入力すると、前の技の隙を途中で切り上げられます。攻撃中には次の入力を450msまで先行受付します。追撃のダメージは85%に補正し、四捨五入します。ガードされた技からはコンボになりません。

攻撃には出るまでの時間と攻撃後の隙があります。被弾すると準備中の攻撃は中断され、同じ時刻に当たる攻撃は相打ちになります。攻撃中と被弾直後の240msはガードできません。その後は攻撃可能になる前でもガードへ戻れます。通常攻撃をガードすると被弾硬直が解け、反撃できます。ガードされた攻撃には命中判定から560msの隙があり、それまでに予約した次の攻撃は取り消します。この隙には新しい攻撃も先行受付しません。強攻撃をガードすると12ダメージを受けます。3連撃、または動けない間の3回連続被弾の後には追撃できない時間を設けています。

HPが0になるか60秒が経過すると決着します。時間切れでは残りHPが多い方の勝利です。同時KOと同じ残りHPは引き分けになります。2人の認識が途切れた場合と設定を開いている間は、戦闘と残り時間を止めます。

## EXゲージと追加技

EXゲージはHPの下に小さく表示し、最大100、開始時50です。通常の攻撃が命中すると攻撃側に8、被弾側に12、ガード成功時には防御側に8加算します。カウンター成功時は反撃側に20加算します。必殺技の命中では攻撃側のゲージは増えません。空振りやポーズの保持では増えず、再戦で50に戻ります。

コンボ脱出は被弾に合わせて両腕を横に開くと発動します。被弾直前に確定した入力も250msだけ受け付け、実際に被弾してから発動します。EXを50消費し、双方の攻撃と予約入力を取り消して800msの無敵時間を得ます。自身は120ms、相手は少なくとも400msの間、新しい行動を始められません。被弾しなかった場合やゲージ不足、KO時には発動せず、消費もしません。腕を開いたままでも予約は延長されません。

カウンターはポーズ確定後の500ms以内にジャブ・ストレートを受けると成功します。強攻撃と必殺技には負けます。空振りすると受付時間の後に600msの隙が残り、途中で攻撃やガードに切り替えられません。成功時の隙は260msです。ポーズを保持しても受付時間は延長されません。

必殺技は攻撃開始時にEXを100消費し、380ms後に命中、攻撃後に800msの隙ができます。ガードされるとダメージ0で、中断されても消費したゲージは戻りません。ジャブ→ストレートの後にL字を作ると、強攻撃の代わりに必殺技で締める3連撃になり、合計40ダメージです。

横に開く腕は肩の高さに置き、手首を肩より外側へ出します。肘を完全に伸ばす必要はありません。コンボ脱出では両腕が少し下がっていても認識します。片腕のカウンターとL字は左右どちらの腕でも使えます。L字では横の腕を肩の高さに、もう片方の手首を十分上に上げてください。必要ゲージが足りない場合はキャラクターの近くに短く表示します。

## 入力の安定化

コンボ脱出は120ms、ジャブ・ストレート・ガードは180ms、両手UP・カウンター・必殺技は260msで確定します。横開きと混同しないよう、新しく手を上げるときの高さには余裕を持たせています。短い判定の揺れは200ms、関節を見失った場合は220ms待ってから解除します。途切れた時間はポーズ確定までの保持時間に加えません。上げた手が肩の高さ付近で少しぶれても、判定を維持します。肘の検出は入力の必須条件にしていません。

これらは実機で調整するための初期値です。服装、照明、体格、カメラとの距離によって、認識漏れや意図しない入力がないかを確認してください。

## カメラなしでの確認

「設定」から「カメラなしで試す」を選びます。キーは次の順にジャブ、ストレート、強攻撃、ガードです。

- 1Pは `A` / `S` / `D` / `F`
- 2Pは `J` / `K` / `L` / `;`

追加技はコンボ脱出・カウンター・必殺技の順に、1Pが `Q` / `W` / `E`、2Pが `U` / `I` / `O` です。

ガードはキーを押している間続きます。キー操作はカメラなしのモードでのみ有効です。

従来の全身骨格の診断画面は `http://127.0.0.1:5173/diagnostics.html` に残しています。

## 実装と検証

`src/upper-body-input.ts` がポーズ判定と再入力を管理し、`src/pose-camera.ts` がカメラとMediaPipeを管理します。`src/combat.ts` は画面から独立した戦闘処理です。`src/game.ts` は入力を戦闘へ渡し、画面と演出を更新します。

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

自動テストではポーズの左右反転と切り替え、判定の揺れ、連発防止、入力領域を確認します。戦闘処理ではゲージの獲得・消費・上限、脱出、カウンター、必殺技、命中時刻、相打ち、中断、ガード、3連撃、連続被弾の上限、KOと時間切れを確認します。左右を交互に10秒間入力するテストでは、最初の被弾後にガードして残りの通常攻撃を防げることを両プレイヤー側で確認します。

MediaPipeのWASM、姿勢モデル、画像はローカルから配信します。カメラ映像や推論結果を外部へ送信・保存する処理はありません。既存のキャラクター画像とCSSを組み合わせて攻撃、被弾、ガード、勝利と敗北を表示しています。画像生成の記録は `public/assets/ANIMATION-v1.md`、`public/assets/GENERATION-v1.md`、`public/assets/UI-v1.md` に残しています。
